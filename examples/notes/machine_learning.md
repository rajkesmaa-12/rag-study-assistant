# Machine learning basics

Gradient descent minimises a loss function by repeatedly moving the parameters in the direction of the negative gradient. The learning rate controls the step size: too large and training diverges, too small and it converges slowly.

Overfitting happens when a model memorises the training data and performs poorly on unseen data. Regularisation, more data, early stopping and dropout reduce overfitting.

Retrieval-augmented generation (RAG) combines a retriever that finds relevant passages with a language model that writes an answer grounded in those passages, which reduces hallucinations.
