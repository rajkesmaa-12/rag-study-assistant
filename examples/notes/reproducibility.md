# Reproducibility Engineering

Repeatability means the same team gets the same result with the same setup. Reproducibility means a different team gets the same result using the original artefacts such as code and data. Replicability means a different team reaches the same conclusion with an independently developed setup.

Docker packages an application and its dependencies into an image. A container is a running instance of an image. Pinning base image versions and dependency versions in the Dockerfile makes builds reproducible.
